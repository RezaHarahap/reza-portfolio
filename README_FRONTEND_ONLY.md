# Portfolio Reza — Frontend Only

Versi ini tidak menggunakan Express API, Supabase database/auth, Cloudinary, atau admin dashboard.
Tampilan publik frontend dipertahankan. Data proyek sekarang dibaca dari `client/src/data/projects.js` dan data sertifikasi dari `client/src/data/certifications.js`.

## Menjalankan lokal

```bash
cd client
npm install
npm run dev
```

Atau dari folder root setelah dependency client terpasang:

```bash
npm run dev
```

## Build

```bash
npm run build
```
