## Run Locally

```bash
cd client
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Build

```bash
cd client
npm run build
```

## Deployment

This portfolio is deployed on **Vercel** and connected to the GitHub repository for continuous deployment.

```text
Local Development
      ↓
GitHub Repository
      ↓
Vercel
      ↓
Production Portfolio
```
